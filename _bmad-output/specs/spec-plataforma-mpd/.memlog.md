- (capability) CAP-1 CSV ingest of eventos: upload a CSV of compras, parsed server-side, persisted as evento records; enrichment arrives as columns, no ERP and no adapters
- (capability) CAP-2 D1 declarative control definitions: the engine executes a control read as data (evento type watched, señales composed, weights, thresholds, delito bound); seeding path exists independently of any UI
- (capability) CAP-3 Reusable señal library: a señal is a detector shared across controles, evidenced by fraccionamiento firing for both soborno y cohecho and lavado de activos
- (capability) CAP-4 Scoring: engine returns {score, breakdown[]} and buckets by pre-configured thresholds into probabilidad baja/media/alta
- (capability) CAP-5 Explicabilidad: the alerta detail shows every señal in the breakdown, whether it fired, its weight and its contribution to the score
- (capability) CAP-6 Ficha del control: auditor-readable rendering of the same declarative definition the engine executed
- (capability) CAP-7 Flujo del encargado: alert queue, open an alerta, review, dismiss, escalate, promote to caso
- (capability) CAP-8 Cierre con justificación: close with a written reason, attributed to a named actor and timestamped; the highest-value evidence record in the system
- (capability) CAP-9 Named actor: Better-Auth session so every review action and cierre has an attributable author; one role is enough for the slice
- (capability) CAP-10 D2 authoring sin código: the encargado authors a control definition through a UI, validated before save, executable by the engine unchanged
- (capability) CAP-11 Measurement harness: run the engine over the synthetic dataset, compare alertas against ground truth, report precisión and recall per control
- (constraint) Scorer never returns a bare number — {score, breakdown[]} enforced in the type signature; the breakdown is persisted with the alerta, not recomputed at read time
- (constraint) Controles are declarative data, never per-control code; adding a delito is configuration
- (constraint) One control definition, three renderings: executable logic, ficha del control, authoring-UI object — no parallel representation of the same control
- (constraint) Thresholds are configuration on the control definition, not constants in the engine and not tuned ad hoc at review time
- (constraint) A human always decides: the system informs and never determines legally; no automatic determination, no blocking action
- (constraint) CSV-only ingest; enrichment arrives as CSV columns (fecha_constitucion_proveedor, flag_PEP, causas_judiciales) so señales relacionales run with zero integrations
- (constraint) Vertical-slice gate: nothing widens until ingest -> score -> explain -> review -> close runs end to end on the demo path
- (constraint) D2 has a pre-committed cutoff date (end of W10); on a miss, stop D2, seed definitions directly and move D2 to trabajo futuro
- (constraint) Domain vocabulary stays Spanish across schema, tRPC procedures and UI; everything else is English
- (constraint) RUT is the entity-resolution join key for proveedor and persona
- (constraint) Build on the existing Better-T-Stack monorepo (React + TanStack Router, Hono + tRPC, Drizzle over SQLite/Turso, Better-Auth, shadcn/ui, Bun, Turborepo); no scaffolding phase, no new stack
- (constraint) Legal derivation is timeboxed to one week and to 2-3 delitos; the method is the contribution, not catalog coverage
- (constraint) Precision over recall: a control that fires too often is a defect, because alert fatigue trains the encargado to dismiss everything
- (constraint) Review actions and cierres are recorded with actor and timestamp and are not editable through the UI (full append-only log and point-in-time storage remain SHOULD, not MUST)
- (decision) Non-goals taken verbatim from the WON'T list plus gestión documental: canal de denuncias, real ERP integration, multi-source enrichment, monitoreo continuo, blocking enforcement, ML in any role including prioritization, multi-tenant
- (decision) Success signal is the demo path on a clean database plus the live-authoring move, with precisión/recall reported per control against an independently planted batch
- (decision) Companions spawned: glossary.md, control-model.md, senales-catalog.md, flujo-del-encargado.md, derivation-chain.md, evaluation-methodology.md, demo-dataset.md, stack-and-conventions.md
